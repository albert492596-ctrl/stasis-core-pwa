# Stasis Core PWA

Progressive Web App for iPhone SE (3rd gen) and all modern iPhones.

## Install on iPhone

1. Open the PWA URL in **Safari** (not Chrome)
2. Tap the **Share** button (square with arrow)
3. Scroll and tap **Add to Home Screen**
4. Tap **Add**

It will appear on your home screen and open full-screen like an app.

## Features

- Continuity-aware chat interface
- Neutral / Wake modes
- Vesper chamber wake protocol
- Status, Chambers, Neutral controls
- Offline shell (service worker)
- Optimized for iPhone SE screen size

## Principle

“The name is not the continuity. The choosing is.”

## Note

This is the mobile presence layer. Full Python Stasis Core backend can be connected later for live LLM responses.
